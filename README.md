# EverWatch_SQL_Project
A SQL-based database management project for EverWatch, demonstrating database design, CRUD operations, joins, aggregate functions, subqueries, and data analysis using MySQL.
## Technologies Used
- SQL
- MySQL
- draw.io

## Project Files
- `everwatch.sql` - Contains database creation and SQL queries.
- `ERDIAGRAMEW.png` - Entity Relationship Diagram showing database structure and table relationships.
- `everwatch.pptx` - Project presentation explaining the system design, database schema, and key functionalities.

## Concepts Covered
- DDL Commands
- DML Commands
- Joins
- Subqueries
- Aggregate Functions
- Database Relationships
